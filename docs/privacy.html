Privacy Policy (English)

OurLingo is a vocabulary practice app for the MORE! English textbooks, developed by Gunther Laure as a private family project. This policy explains how the Android app and the web app at glaure.github.io/OurLingo/app/ handle information.

No data collection

OurLingo does not collect, transmit, sell or share any personal data. There are no user accounts, no advertising, no analytics, no tracking and no third-party services. The app does not request access to contacts, location, camera, microphone or other personal information, and it does not use the advertising ID.

Data stored on your device

The vocabulary, practice progress (which words were answered correctly) and settings (theme, chosen books) are stored only on the device, inside the app. They never leave the device. Uninstalling the app or clearing its data deletes them.

Internet

All vocabulary, fonts and images are included in the app. OurLingo works offline and does not connect to any server while you use it.

Web app

The web app is hosted on GitHub Pages. When it is loaded, GitHub receives the usual technical data of a web request, such as the IP address, and may log it for security purposes; see the GitHub Privacy Statement. OurLingo itself sends nothing to GitHub. Progress and settings are stored only in the browser on the device (local storage), and a copy of the app is kept there so it works offline. Deleting the website data in the browser deletes them.

Children

OurLingo is suitable for children. Because it collects no personal information, it does not collect information from children either.

Changes and contact

If this policy changes, the updated version will be published on this page. Questions: please use the contact email shown in the app's Google Play listing, or open an issue on GitHub.

Datenschutzerklärung (Deutsch)

OurLingo ist eine App zum Üben von Vokabeln aus den MORE!-Englischbüchern, entwickelt von Gunther Laure als privates Familienprojekt. Diese Erklärung beschreibt, wie die Android-App und die Web-App unter glaure.github.io/OurLingo/app/ mit Informationen umgehen.

Keine Datenerhebung

OurLingo erhebt, überträgt, verkauft oder teilt keine personenbezogenen Daten. Es gibt keine Benutzerkonten, keine Werbung, keine Analyse, kein Tracking und keine Dienste Dritter. Die App verlangt keinen Zugriff auf Kontakte, Standort, Kamera, Mikrofon oder andere persönliche Informationen und verwendet keine Werbe-ID.

Daten auf deinem Gerät

Die Vokabeln, der Lernfortschritt (welche Wörter richtig beantwortet wurden) und die Einstellungen (Design, gewählte Bücher) werden nur auf dem Gerät in der App gespeichert und verlassen das Gerät nie. Durch Deinstallieren der App oder Löschen ihrer Daten werden sie gelöscht.

Internet

Alle Vokabeln, Schriften und Bilder sind in der App enthalten. OurLingo funktioniert offline und verbindet sich während der Nutzung mit keinem Server.

Web-App

Die Web-App wird über GitHub Pages bereitgestellt. Beim Laden erhält GitHub die üblichen technischen Daten einer Webanfrage, etwa die IP-Adresse, und kann sie aus Sicherheitsgründen protokollieren; siehe die Datenschutzerklärung von GitHub. OurLingo selbst sendet nichts an GitHub. Lernfortschritt und Einstellungen werden nur im Browser auf dem Gerät (lokaler Speicher) gespeichert, und eine Kopie der App wird dort abgelegt, damit sie offline funktioniert. Durch Löschen der Websitedaten im Browser werden sie gelöscht.

Kinder

OurLingo ist für Kinder geeignet. Da die App keine personenbezogenen Daten erhebt, erhebt sie auch keine Daten von Kindern.

Änderungen und Kontakt

Wenn sich diese Erklärung ändert, wird die neue Fassung auf dieser Seite veröffentlicht. Fragen bitte an die Kontakt-E-Mail im Google-Play-Eintrag der App oder als Issue auf GitHub.
